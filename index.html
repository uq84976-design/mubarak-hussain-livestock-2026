Features

Everything is a flag on one endpoint

No dashboards required. Read the fourteen things below, then never think about hosting again.

API-first

One endpoint, three body formats: raw HTML, JSON multi-file (binaries as base64), or a zip — with the root directory auto-stripped so dist/ archives just work.

Own subdomain per drop

Every drop mounts at the root of its own subdomain. Absolute paths like /app.js and /styles.css just work — no base-path rewrites, ever. On Pro, name up to 5 of your own, like you.ship.place.

GET /app.js → 200
Explore all features

Unguessable URLs

Sharing IS the access control: ~47 bits of entropy per URL. Anyone with the link can view — no login — and nobody without it will find it.

Custom TTL

Choose a lifetime with ?ttl= (minimum 60 seconds). Pro pages stay online while you're on Pro. 

POST /deploy?ttl=3600

FAQ

Asked often enough

Anyone with the link — and nobody without it: every URL carries ~47 bits of entropy, so guessing one is a one-in-120-trillion shot.

Publish without an account. Claim the page with a free account (no card) and it stays online as long as you keep it. Pro pages don't expire while you're on Pro and can be updated without changing the link. Pro is $4 a month and also includes badge-free pages, up to 5 custom subdomains like you.ship.place, an AI editor with 50 credits a month and 90-day analytics (sources, countries, devices).

Subscribers can redeploy a named drop (?name=…) and the URL keeps serving the new content. Anonymous drops can't be edited in place, but every anonymous deploy returns a one-time claim token — save it and you can attach the drop to your account from the dashboard later.

Nothing illegal or harmful — no malware, phishing or scams; report anything bad with the report form, or email abuse@bitgate.com for legal notices.

Yes — curl IS the product: everything on this page is a flag on POST /deploy, and there's a GitHub Action for CI. See the API docs and the GitHub Action.

When Pro ends, the pages it kept from expiring expire with it, and paid features stop applying to new deploys.
